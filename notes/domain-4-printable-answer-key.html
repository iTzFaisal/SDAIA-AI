1. Which record most directly links a served prediction to the components and approval evidence used for its release?

  1. A screenshot of the largest training score
  2. An unversioned folder called final
  3. A release manifest referencing compatible versions and evaluation records
  4. The current production alias without historical resolution

Correct: C.

  • A: A single score does not identify the served bundle, evaluation basis, or approval.
  • B: A mutable folder name does not preserve a stable component identity.
  • C: The manifest ties the actual serving configuration to identifiable evidence and artifacts.
  • D: Today's alias may refer to a different model from the one that served the prediction.

2. An evaluation score rises after the model judge and rubric change, while the assistant itself is unchanged. Which conclusion is best supported?

  1. The measurement basis changed; compare on a controlled common rubric before claiming improvement
  2. The assistant necessarily learned new weights
  3. The new score can replace all old records without qualification
  4. A larger judge makes human calibration unnecessary

Correct: A.

  • A: A changed evaluator can change scores without any change to the assistant's answers.
  • B: No assistant change is described; a score is not evidence of parameter updating.
  • C: Removing the evaluator distinction makes historical comparisons misleading.
  • D: Judge size does not eliminate bias or the need to validate the evaluation process.

3. A retrieval complaint traces to index I14. What additional lineage evidence is most useful for finding a bad source?

  1. Only the support agent's display name
  2. Only the total number of model parameters
  3. Every user's full conversation history with unrestricted access
  4. Corpus snapshot, document versions/effective dates, chunking, and embedding/index build records

Correct: D.

  • A: A person's name does not identify documents or transformations used to build the index.
  • B: Parameter count cannot identify the wrong corpus version or source transformation.
  • C: Broad private histories are unnecessary and introduce exposure without precise source lineage.
  • D: These links establish which evidence entered I14 and how it was transformed.

4. A hosted model has been retired despite an exact local record of its prior version and seed. What should the team acknowledge?

  1. The seed can recreate the hosted service without its artifacts
  2. Records preserve identity, not guaranteed remote availability; use an evaluated continuity plan
  3. Any replacement with the same output schema is automatically equivalent
  4. Erase the old release identity so users cannot notice a change

Correct: B.

  • A: A random seed does not recreate inaccessible weights, infrastructure, or provider behavior.
  • B: Reproducibility documentation cannot force a provider to keep a retired model accessible.
  • C: Task behavior, refusals, quality, timing, and cost can differ despite shared structure.
  • D: Deleting records conceals the dependency change and harms diagnosis and accountability.

5. Which statement correctly relates retraining to deployment?

  1. New data must automatically replace the production model
  2. Retraining creates a candidate that still needs quality and release checks
  3. Deployment always requires learning new parameters
  4. A training pipeline cannot fail if it is automated

Correct: B.

  • A: Updated data can be invalid or unrepresentative; candidates need release evidence.
  • B: Training and promotion are distinct decisions, even when both have automated stages.
  • C: Prompt, index, configuration, or software releases may involve no training.
  • D: Automation repeats defined behavior; it does not guarantee valid inputs or successful stages.

6. A candidate reduces overall error but violates a predeclared minimum for an important small region. What is the most defensible gate decision?

  1. Approve because the region contributes few requests
  2. Lower the region's minimum after seeing the failure and call the original gate passed
  3. Deploy first and evaluate the region only if users complain
  4. Block promotion, inspect representative slice evidence, and repair or reject the candidate

Correct: D.

  • A: Low volume does not override a stated critical requirement for that region.
  • B: Changing the criterion to fit a result undermines the claimed approval evidence.
  • C: The known failing gate warrants repair before broader exposure.
  • D: Release gates must enforce the actual constraints, not only the favorable overall average.

7. A prompt and tool-policy update bypasses the release pipeline because application code did not change. What is the strongest concern?

  1. Behavior and permissions can change without code changes and need risk-bearing gates
  2. Only trained weight files can change an AI application's behavior
  3. A prompt edit is always safer than a code edit
  4. The update requires changing the official domain weights

Correct: A.

  • A: Prompts and tool policies are release components that can affect correctness and authority.
  • B: Retrieval, prompts, settings, and tool constraints also shape outputs and actions.
  • C: Safety depends on consequences and controls, not the file category alone.
  • D: Engineering changes do not alter the supplied assessment blueprint.

8. A staging test passes using one scaler, but production packaging silently includes another fitted scaler. What should a release check establish?

  1. Only that both files have similar names
  2. Only that training loss is low
  3. The actual promoted bundle has the tested model, preparation, contract, and environment
  4. That production can fit a new scaler on each request

Correct: C.

  • A: Similar names do not establish identical learned preparation or compatibility.
  • B: Training fit does not exercise the wrongly packaged serving configuration.
  • C: Testing the real identified artifact bundle catches packaging divergence from approved evidence.
  • D: Refitting on requests changes preparation and does not restore the approved trained process.

9. Which statement correctly distinguishes online inference from online learning?

  1. Both must update model weights for every request
  2. Online inference can only use last month's stored outputs
  3. Online learning means the response contains a hyperlink
  4. Online inference serves arriving requests; online learning updates the learned model incrementally

Correct: D.

  • A: Serving predictions does not inherently perform parameter updates.
  • B: It computes outputs for arriving requests rather than requiring old precomputed predictions.
  • C: The term concerns learning updates, not browser navigation or links.
  • D: Prediction-time computation and parameter adaptation are different operations.

10. A shadow test copies refund requests to a candidate with access to the live payment tool. Which control is essential?

  1. Allow payments because candidate answers are not shown to users
  2. Block or simulate consequential execution outside the model and protect copied data
  3. Use only a prompt asking the candidate to avoid payments
  4. Give copied refunds new identities to avoid sharing results

Correct: B.

  • A: Hidden outputs do not prevent real external effects from tool execution.
  • B: Shadow comparison must not duplicate refunds or bypass data-handling restrictions.
  • C: Prompt instructions cannot replace enforced control of payment authority.
  • D: New identities can create separate duplicate payments rather than prevent them.

11. A canary receives 1,000 of 20,000 requests and fails 80; the control fails none. What are candidate and overall error rates?

  1. Candidate 0.4%; overall 8%
  2. Candidate 4%; overall 4%
  3. Candidate 8%; overall 0.4%
  4. Both 0%, because the control succeeded

Correct: C.

  • A: This reverses the denominators: the candidate uses 1,000 requests and overall uses 20,000.
  • B: Neither stated fraction equals 80/1,000 or 80/20,000.
  • C: 80/1,000 = 8%; 80/20,000 = 0.4%, showing why per-version monitoring matters.
  • D: A healthy control does not erase failures experienced by the candidate's users.

12. A new blue-green environment changed shared persistent data in a form the old application cannot read. Is routing traffic back sufficient recovery?

  1. No; recovery needs a safe data-compatibility plan as well as routing
  2. Yes; blue-green guarantees all state changes are reversible
  3. Yes; the old model's validation score proves it can read any schema
  4. No; permanently disabling every unrelated service is always necessary

Correct: A.

  • A: A traffic switch cannot repair state that the previous version no longer understands.
  • B: Prepared environments do not automatically isolate or reverse shared data migrations.
  • C: Model quality evidence does not establish application compatibility with changed data.
  • D: The response should address affected scope and safe recovery, not indiscriminate shutdown.

13. Similar parcel features now imply longer arrival times after a road-access change. Which change does this most directly illustrate?

  1. Concept drift
  2. A necessarily malformed JSON response
  3. Only a larger fraction of long-distance inputs
  4. Proof of a credential expiry

Correct: A.

  • A: The relationship between available inputs and the target duration has changed.
  • B: A changed real-world relationship can occur while syntax and schema remain valid.
  • C: Input proportions alone are different from changed outcomes for similar features.
  • D: The described outcome shift does not establish an authentication failure.

14. Confirmed fraud labels can take 30 days. The team labels yesterday's unconfirmed transactions as legitimate to report recall. What is the best correction?

  1. Keep the report because no complaint means no fraud
  2. Report training recall as yesterday's live recall
  3. Use adequately mature event-time cohorts and report label delay, coverage, and selection
  4. Remove all positive labels so the metric becomes stable

Correct: C.

  • A: Absence of an early complaint is not a confirmed negative outcome.
  • B: Training performance is not evidence about yesterday's operational cohort.
  • C: Delayed outcomes require appropriate follow-up and qualified performance claims.
  • D: Discarding outcomes changes and biases the evidence rather than correcting its timing.

15. A feature table stopped updating last week and predictions deteriorate. Which first response is best supported?

  1. Immediately replace the model with a larger neural network
  2. Investigate and repair the freshness fault, then verify predictions and pipeline health
  3. Classify every future alarm as harmless seasonality
  4. Hide the freshness metric to reduce alert volume

Correct: B.

  • A: Model capacity does not repair stale feature data.
  • B: The concrete stale-input fault should be corrected before assuming retraining is the remedy.
  • C: A known broken update path is not evidence that later changes are benign seasonal effects.
  • D: Concealing the signal does not restore current inputs or task quality.

16. A recommendation model is retrained only on clicks from items it previously chose to display. What risk should be assessed?

  1. Click feedback is always independent of the model's decisions
  2. More epochs necessarily remove missing-item coverage
  3. Every clicked item is guaranteed to satisfy the user's true need
  4. A feedback loop can reinforce selected exposure and hide useful unshown items

Correct: D.

  • A: The model influences exposure, which influences which clicks can be observed.
  • B: Repeated fitting does not create observations about items that were never displayed.
  • C: Clicks are a proxy influenced by position, curiosity, and exposure, not unquestionable task truth.
  • D: Evidence collection must account for model-induced selection rather than treating observed clicks as neutral coverage.

17. A p95 latency is 1.5 seconds for a defined request set. What does that measurement most directly describe?

  1. Every request completes within 1.5 seconds
  2. The mean response time is exactly 1.5 seconds
  3. Roughly 95% of measured requests complete within that value
  4. 95% of generated facts are correct

Correct: C.

  • A: A percentile leaves a tail of slower requests and is not a universal maximum.
  • B: A percentile is a distribution position rather than an arithmetic average.
  • C: The percentile describes latency distribution under the stated measurement basis, not quality.
  • D: Response time cannot establish factual correctness.

18. A fixed-count window has 40,000 eligible requests and a 99.5% good-response objective. With 150 bad requests, what remains in the request error budget?

  1. 50 bad requests
  2. 200 bad requests
  3. 39,800 bad requests
  4. 50 unauthorized disclosures

Correct: A.

  • A: The allowance is 40,000 × 0.005 = 200; subtracting 150 leaves 50 under this fixed counting basis.
  • B: Two hundred is the full allowance before the 150 observed bad requests are deducted.
  • C: That is the required good count, not the remaining bad allowance.
  • D: A reliability error budget is not permission to violate authorization or privacy rules.

19. A support assistant receives 200 requests, answers 120, and 90 answers pass its quality rubric. Which summary uses the correct denominators?

  1. 75% coverage; 60% of answers pass
  2. 90% coverage; 120% of answers pass
  3. 75% of all requests produced passing answers
  4. 60% answer coverage; 75% of answers pass

Correct: D.

  • A: This swaps 120/200 coverage with 90/120 quality among answers.
  • B: Raw counts are not percentages, and neither figure uses the required denominator.
  • C: 90/200 = 45% of all requests produced a passing answer, not 75%.
  • D: 120/200 = 60% coverage and 90/120 = 75% pass rate among answered requests.

20. Latency and token cost rise after an agent update despite unchanged request volume. Which evidence is most useful and proportionate?

  1. Only the request count, because cost must track it exactly
  2. Minimized traces of stages, attempts, tool loops, versions, durations, and token accounting
  3. Unrestricted logs of every prompt, credential, and tool reply
  4. Only model-judge answer scores

Correct: B.

  • A: More calls, longer context, or retries per request can change cost independently of volume.
  • B: Linked stage metadata can distinguish retrieval delay, repeated calls, and prompt growth without indiscriminate content retention.
  • C: Raw sensitive logging is disproportionate and can expose secrets and private records.
  • D: Answer ratings do not identify where operational latency or repeated token usage arises.

21. Which statement best describes a post-incident review that can reduce recurrence?

  1. Identify one person to blame and close every follow-up
  2. Document impact, timeline, contributing conditions, and corrective actions with owners and checks
  3. Declare prevention complete as soon as a report is written
  4. Delete the timeline so future teams cannot repeat the investigation

Correct: B.

  • A: Blame alone does not repair contributing conditions or verify preventive changes.
  • B: Owned, verifiable changes turn incident learning into improvements in gates, monitoring, and recovery.
  • C: A document without implemented and verified actions does not reduce recurrence.
  • D: Necessary minimized records support learning and clear operational handoffs.

22. The normal provider fails and a backup has never been tested for this application's contracts or quality. Which response is safest?

  1. Switch silently because any provider is equivalent
  2. Disable output checks so backup responses always count as success
  3. Return invented successful answers until the provider recovers
  4. Use an already evaluated safe degradation or an honest unavailable/manual path

Correct: D.

  • A: Contract, task quality, permission handling, and failure behavior can differ across providers.
  • B: Bypassing validation hides errors and can introduce unsafe downstream actions.
  • C: Fabricating success conceals the outage and misleads users.
  • D: An unverified substitute is not a recovery guarantee; approved alternatives preserve the task's constraints.

23. A deployment command succeeds after an outage, but queued jobs and user-facing quality have not been checked. What is still required?

  1. Verify user-visible recovery, permissions, quality, and outstanding work
  2. Close the incident solely because the command exited successfully
  3. Treat every queued consequential action as never executed
  4. Replace the SLO with the deployment exit code

Correct: A.

  • A: Deployment success is an intermediate event, not proof that the full service and affected operations recovered.
  • B: A successful command does not establish downstream results or user experience.
  • C: Some outcomes may be uncertain and require authoritative reconciliation before replay.
  • D: An internal command result is not a meaningful substitute for the user's defined service outcome.

24. A prior release would restore fast answers but would also restore a revoked document-access rule. What is the strongest recovery decision?

  1. Restore it because availability overrides all access constraints
  2. Keep the new unsafe answers active until the full root cause is proven
  3. Preserve current authorization, contain the affected feature, and use a verified compatible repair or fallback
  4. Ask the model to hide any newly exposed documents in its final prose

Correct: C.

  • A: Reliability goals cannot authorize access that has been revoked.
  • B: Ongoing harm can be contained without waiting for complete causal certainty.
  • C: Recovery must remain safe under current access rules; an old bundle is not automatically an acceptable rollback target.
  • D: Prompt-based concealment does not enforce access boundaries before protected retrieval.
