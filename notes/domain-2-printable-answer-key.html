1. A planner represents a robot's location and battery charge, permitted moves, and a destination. What is battery charge in this formulation?

  1. A generated answer's citation
  2. A neural network learning rate
  3. Part of the search state
  4. The final reward for every episode

Correct: C.

  • A: Battery charge is part of the modeled situation, not a source reference.
  • B: Learning rate configures parameter updates, not the robot's current condition.
  • C: Charge can affect feasible actions and therefore belongs in the state representation.
  • D: Current charge is not necessarily the reward or the goal value.

2. A finite route graph has varying nonnegative toll costs. The objective is least total toll, not fewest roads. Which search priority fits most directly?

  1. Lowest accumulated path cost, with correct repeated-state handling
  2. Deepest path discovered so far
  3. Fewest roads without considering tolls
  4. Highest estimated remaining cost only

Correct: A.

  • A: Uniform-cost search orders paths by their cost rather than their step count.
  • B: Depth-first exploration does not generally minimize total toll.
  • C: Shallowest paths can be more expensive under unequal toll costs.
  • D: Favoring high remaining cost does not target the cheapest route.

3. A team calls a support system reinforcement learning solely because it makes several tool calls in sequence. Which response is best?

  1. Sequential calls alone prove reward-based learning
  2. Any system with a language model must use reinforcement learning at runtime
  3. Tool calls make the system a convolutional network
  4. Ask whether an action policy is learned from reward feedback

Correct: D.

  • A: A workflow can be sequential without learning from rewards.
  • B: A trained model can be used without runtime reward-driven updates.
  • C: Tool use says nothing about convolutional architecture.
  • D: Reward-based policy learning, not mere sequence length, is the defining distinction.

4. A team uses A* with a guessed remaining-cost heuristic that sometimes overestimates. It claims lowest-cost results are guaranteed just because f = g + h. What is the best assessment?

  1. The formula alone proves optimality
  2. The guarantee is not established; check heuristic and algorithm conditions
  3. Overestimation always improves optimality
  4. Replacing path costs with model confidence preserves the objective

Correct: B.

  • A: Optimality also depends on heuristic properties and search handling.
  • B: An overestimating guess lacks the usual admissibility basis for the claim.
  • C: It can steer search away from the truly cheapest route.
  • D: Confidence is not the stated route-cost measure.

5. A network stacks weighted sums and biases but no nonlinear hidden activations. What can be said about the resulting mapping?

  1. Every extra layer necessarily introduces nonlinear structure
  2. It is still an affine mapping despite the additional layers
  3. It must be a retrieval system rather than a model
  4. It is automatically calibrated

Correct: B.

  • A: Composing linear/affine transformations alone remains linear/affine.
  • B: Weighted sums and biases compose into another weighted sum plus bias.
  • C: The activation choice does not define document retrieval.
  • D: Neither depth nor linearity establishes probability reliability.

6. Under simple gradient descent, a weight is 0.8, its gradient is −0.3, and learning rate is 0.2. What is its updated value?

  1. 0.74
  2. 0.5
  3. 0.06
  4. 0.86

Correct: D.

  • A: This adds learning rate times gradient instead of subtracting it.
  • B: This subtracts the gradient magnitude without applying the learning rate.
  • C: This is the magnitude of the step, not the new weight.
  • D: New weight = 0.8 − 0.2 × (−0.3) = 0.86.

7. A team changes only the inference prompt of a frozen deployed model. Which statement about the model's learned weights is justified?

  1. They are unchanged by ordinary prompting
  2. They are retrained once for each token in the prompt
  3. They become permanently adapted to that user's examples
  4. They shrink because fewer training epochs are used

Correct: A.

  • A: Context can affect output without a gradient-based parameter update.
  • B: Token processing is not itself a training update.
  • C: Prompt context is not permanent weight learning.
  • D: Inference prompting does not change the trained parameter count.

8. On an audited neural-network split, training loss keeps improving but validation loss worsens late in training. Which action fits the evidence?

  1. Select the final epoch solely because training loss is lowest
  2. Tune dropout on the final test until its score peaks
  3. Consider validation-based early stopping or regularization
  4. Declare vanishing gradients from the generalization gap alone

Correct: C.

  • A: This ignores the observed deterioration on unseen development cases.
  • B: That would contaminate final evaluation.
  • C: The pattern suggests overfitting; select remedies using validation, not the final test.
  • D: A train/validation gap does not specifically diagnose vanishing gradients.

9. Which family directly carries a hidden state from one sequence step to the next?

  1. A road-search heuristic
  2. A fixed fee table
  3. A standard local convolution filter
  4. A recurrent neural network, such as an LSTM

Correct: D.

  • A: A heuristic estimates remaining cost rather than defining recurrent computation.
  • B: A rule table is not a learned sequential state model.
  • C: Convolution shares local filters rather than the described recurrent state.
  • D: Recurrent families update state across the sequence.

10. Two sentences use the same tokens but reverse who pays whom. What helps a transformer distinguish their order?

  1. Token IDs sorted numerically
  2. Position information alongside token representations
  3. An extra training/test leak
  4. A source citation attached after generation

Correct: B.

  • A: Sorting IDs discards the original sequence rather than encoding it.
  • B: Attention needs sequence-order information to distinguish otherwise similar token sets.
  • C: Leaked answers are not a valid representation technique.
  • D: A citation does not encode the original token order.

11. A company has limited labeled defect images and access to a suitably licensed pretrained vision model. Which initial experiment is strongest?

  1. Assume the public benchmark score proves factory performance
  2. Use only a text generator because deep learning means language
  3. Train a head on frozen features and evaluate representative held-out images
  4. Remove low-light test images to match the pretrained dataset

Correct: C.

  • A: Domain-specific lighting, cameras, and defects may differ.
  • B: Deep learning includes vision and many non-generative tasks.
  • C: Transfer learning is a reasonable starting point, with honest task-specific validation.
  • D: Removing required deployment cases hides the mismatch rather than solving it.

12. An analyst presents one self-attention heatmap as complete proof of why a transformer made a harmful decision. What is the best response?

  1. Treat it as limited evidence, not a full causal explanation
  2. Accept it because all model behavior is a single attention head
  3. Declare attention impossible during inference
  4. Replace factual evaluation with the heatmap alone

Correct: A.

  • A: Attention weights show some information weighting, not all computations or causal effects.
  • B: Transformers contain multiple heads, layers, and other transformations.
  • C: Attention is part of the model's forward computation too.
  • D: A visualization cannot establish task correctness or safety by itself.

13. Which description fits a text-to-image diffusion model most directly?

  1. Generating through learned iterative denoising, conditioned on text
  2. Finding a minimum-toll path through a road graph
  3. Training only a generator against a real/fake discriminator
  4. Filling a fixed fee table without learned representations

Correct: A.

  • A: Diffusion generation reverses a noising process using learned denoising steps.
  • B: That is search over structured states and costs.
  • C: That describes a GAN more directly than diffusion.
  • D: That describes rules, not the generative model family.

14. A simplified shared 6,000-token budget uses 800 for instructions, 1,200 for history, 2,500 for evidence, and reserves 700 for output. How much remains?

  1. 1,500 tokens
  2. 5,200 tokens
  3. 800 tokens
  4. 2,000 words

Correct: C.

  • A: This omits the reserved output from the total usage.
  • B: This is the used budget, not what remains.
  • C: 6,000 − (800 + 1,200 + 2,500 + 700) = 800.
  • D: The stated budget is in tokens, and tokens are not interchangeable with words.

15. The word 'port' has different meanings in a shipping report and a network manual. Which representation is designed to use this surrounding context?

  1. A vocabulary ID treated as a numerical quantity
  2. A contextual embedding
  3. A single static word vector for every occurrence
  4. A temperature setting alone

Correct: B.

  • A: The ID identifies a token and does not model surrounding meaning.
  • B: Contextual representations incorporate neighboring information to distinguish usage.
  • C: A static vector does not change with the sentence context.
  • D: Temperature controls sampling rather than encoding word sense.

16. A generated answer has high token likelihood but cites a nonexistent report. Which conclusion is most justified?

  1. The report must exist because the continuation is likely
  2. A larger context limit alone validates the citation
  3. Using the same random seed makes the report factual
  4. Plausible generation can still be unsupported; verify the citation

Correct: D.

  • A: Likelihood under a model is not evidence of external existence.
  • B: Capacity to accept context does not verify a report.
  • C: Reproducibility and factual validity are different properties.
  • D: External claims need evidence beyond the model's continuation probabilities.

17. Which intervention necessarily involves training parameters rather than only supplying request context?

  1. Including two formatted examples in a prompt
  2. Appending retrieved approved excerpts
  3. Training parameter-efficient adapters on reviewed task examples
  4. Changing the requested answer length

Correct: C.

  • A: Few-shot examples can be used at inference without parameter updates.
  • B: Providing evidence in context does not require training the generator.
  • C: Adapter adaptation trains learned parameters even with base weights frozen.
  • D: An instruction changes the request, not learned weights.

18. A policy assistant retrieves the headline rule but misses an exception in the next paragraph because chunks are tiny. Which change should be evaluated first?

  1. Chunk boundaries and enough surrounding context to preserve conditions
  2. A stronger style fine-tune with the same incomplete evidence
  3. Removing all effective-date metadata
  4. A higher sampling temperature for more diverse exceptions

Correct: A.

  • A: The evidence is fragmented; chunking and context assembly are direct diagnostic levers.
  • B: Style adaptation does not supply the missing exception.
  • C: That loses important authority and freshness information.
  • D: Sampling variety is not a substitute for the actual policy evidence.

19. A relevant paragraph is found by lexical search and then supplied to a generator. The team says it cannot be RAG without a vector database. What is correct?

  1. RAG is defined only by a specific database technology
  2. Lexical search changes the generator's weights
  3. It becomes fine-tuning because the paragraph contains examples
  4. Retrieval can be lexical, vector-based, or hybrid in a RAG workflow

Correct: D.

  • A: The defining relationship is retrieval supporting generation.
  • B: Supplying retrieved text does not itself update generator parameters.
  • C: Examples in inference context do not constitute a training update.
  • D: A vector database is an implementation choice, not a universal requirement.

20. A cross-department assistant indexes restricted documents. A team proposes retrieving everything, then asking the model not to reveal unauthorized text. What is the strongest correction?

  1. Increase chunk size to make restricted passages less noticeable
  2. Enforce user permissions before restricted content enters the answer context
  3. Keep the design if answers include citations
  4. Fine-tune the model to memorize department names

Correct: B.

  • A: Obscuring content does not enforce access control.
  • B: Authorization must be an application boundary, not a model's voluntary disclosure rule.
  • C: Citations can themselves expose restricted information and do not authorize access.
  • D: Memorized names do not establish enforceable document permissions.

21. For one query, four passages are known relevant. Two appear in the top five retrieved passages. Under passage-level recall@5, what is recall?

  1. 40%
  2. 50%
  3. 80%
  4. 100%

Correct: B.

  • A: Two of five is precision among retrieved passages, not the defined recall.
  • B: Recall@5 = two relevant passages retrieved / four known relevant passages.
  • C: Four divided by five does not count retrieved relevant evidence.
  • D: Two relevant passages are still missing from the top-five candidates.

22. A summarizer gets a high lexical-overlap score while reversing whether a request was approved. What should the evaluator conclude?

  1. Shared words establish correct meaning
  2. The score can replace every human-reviewed case
  3. The source must be removed because overlap is high
  4. Add semantic correctness checks; overlap alone misses the failure

Correct: D.

  • A: Overlap can remain high when a critical decision is reversed.
  • B: Important semantic errors need task-specific correctness checks.
  • C: The score alone does not identify a source defect.
  • D: A decision reversal violates the task despite many matching words.

23. An LLM judge consistently prefers longer answers even when experts flag unsupported details. What is the best next step?

  1. Calibrate the rubric and judge against expert cases and inspect disagreement
  2. Make every candidate answer longer to win the score
  3. Treat the judge as authoritative because it is another model
  4. Reuse final-test answers as fine-tuning examples and keep the same final score

Correct: A.

  • A: The measurement component has a bias that must be evaluated rather than assumed correct.
  • B: This optimizes the judge's bias, not grounded answer quality.
  • C: Models used for evaluation are also fallible.
  • D: That contaminates the final evaluation boundary.

24. A tool-using agent usually finishes correctly but sometimes retries a money-transfer call after a timeout and transfers twice. Which evaluation and safeguard fit best?

  1. Score only the final explanation and increase temperature
  2. Allow unlimited retries to maximize eventual completion
  3. Inspect action traces and enforce duplicate-action protection, limits, and approval
  4. Hide tool logs so the model focuses on the goal

Correct: C.

  • A: The harmful side effect is not captured by fluency or sampling variety.
  • B: Unbounded repeated actions can compound financial harm.
  • C: Evaluate side effects and recovery; application controls must bound consequential actions.
  • D: Removing evidence makes diagnosis and oversight weaker.
