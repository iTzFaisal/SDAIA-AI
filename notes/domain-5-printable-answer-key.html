1. A team needs to store versioned image datasets and model artifacts as individually addressed items. Which storage abstraction most directly fits?

  1. A semantic answer cache as the only persistent store
  2. Object storage with appropriate version, access, and recovery controls
  3. Only each application replica's temporary memory
  4. A transaction status inferred from embeddings

Correct: B.

  • A: Temporary answer reuse is not a durable source for datasets and release artifacts.
  • B: Individually addressed objects suit these artifacts, while actual durability and access requirements still need verification.
  • C: Temporary local memory loses required artifacts when the instance disappears.
  • D: Similarity results do not provide the artifact storage or authoritative status required.

2. A routing service adds replicas, but job status is saved only in the replica that accepted the job. What is the main design risk?

  1. The model automatically becomes better calibrated
  2. The vector dimension must increase
  3. The system can no longer use object storage
  4. Rerouting or instance loss can lose or contradict required job progress

Correct: D.

  • A: Application state placement does not establish probability calibration.
  • B: Embedding dimensionality is unrelated to preserving job state across replicas.
  • C: Adding application replicas does not prohibit appropriate artifact storage.
  • D: Unique local durable truth makes replaceability unsafe unless progress is preserved in an appropriate shared system.

3. A lost vector index must be rebuilt. Which evidence is most important for a compatible, safe reconstruction?

  1. Authorized source versions, transformation/embedding configuration, and current access/deletion state
  2. Only the application's color scheme
  3. Any embedding model with the same vector length
  4. Old final answers copied back as authoritative documents

Correct: A.

  • A: Rebuilding requires lineage and compatibility, while current access and legitimate deletion requirements must survive recovery.
  • B: Visual settings do not reproduce searchable representations or permission behavior.
  • C: Equal dimensionality does not guarantee query and document vectors inhabit compatible learned spaces.
  • D: Generated outputs are not a trustworthy substitute for approved source material.

4. A team proposes separate services for every small transformation despite low traffic and no need to scale them independently. What is the strongest architecture review?

  1. Approve because more network boundaries always improve reliability
  2. Reject all service boundaries in every future system
  3. Compare with a simpler design using requirements, ownership, latency, and failure costs
  4. Choose whichever design uses the most expensive hardware

Correct: C.

  • A: Every boundary adds dependencies and possible failures rather than automatically improving reliability.
  • B: Some boundaries earn their place through isolation, ownership, or independently constrained workloads.
  • C: Complexity should be justified by the constraints and operational tradeoffs, not component count.
  • D: Price is not evidence that the architecture meets task and operating requirements.

5. A small CPU-served classifier already meets quality and response targets at low volume. What evidence is needed before moving it to a GPU?

  1. Only the word accelerator in a product description
  2. A claim that GPUs make predictions more correct
  3. Comparable end-to-end workload measurements including transfer overhead and total cost
  4. The official badge level the GPU will award

Correct: C.

  • A: A hardware category does not establish actual workload benefit.
  • B: Hardware does not automatically improve the learned decision's task quality.
  • C: The intended journey and demand determine whether GPU execution provides a justified benefit.
  • D: Infrastructure purchases do not confer exam awards or official readiness.

6. Ignoring metadata, 4 billion weights move from 16-bit to 8-bit representation. Using decimal units, what happens to raw weight storage?

  1. 8 GB becomes 4 GB; total serving memory still needs measurement
  2. 8 GB becomes 4 GB, guaranteeing twice the end-to-end speed
  3. 4 GB becomes 8 GB
  4. The model uses no memory because all weights are integers

Correct: A.

  • A: Each weight changes from two bytes to one, while non-weight allocations are excluded.
  • B: The storage arithmetic is right, but runtime operations, transfers, and other stages determine speed.
  • C: This reverses the effect of reducing bits per weight.
  • D: Integer representations still consume storage and working memory.

7. Weights fit in accelerator memory, but long prompts and many simultaneous generations cause allocation failures. Which diagnosis is best supported?

  1. The weight-size estimate must include every possible request automatically
  2. Current access checks can be removed to make the model fit
  3. The model has proven concept drift
  4. Working buffers and concurrent sequence state, including KV cache, exceed remaining memory

Correct: D.

  • A: Raw weight storage deliberately excludes request-dependent state and working allocations.
  • B: Permissions must remain enforced and are not a remedy for serving memory pressure.
  • C: Memory exhaustion is an operational capacity symptom, not proof of a changed input-outcome relationship.
  • D: Context lengths and simultaneous sequences can make total serving memory much larger than weights alone.

8. One model is divided across two devices to fit. A manager expects exactly twice the throughput. What is the strongest correction?

  1. Model parallelism is always the same as two independent serving replicas
  2. Fitting and speedup are different goals; communication and the workload must be measured
  3. Every extra device necessarily halves task accuracy
  4. Data parallelism means storing half of each model on each device

Correct: B.

  • A: A divided model can require both devices for each request rather than independently handling two requests.
  • B: Splitting computation helps capacity but introduces inter-device work and does not guarantee linear throughput gains.
  • C: There is no universal accuracy-halving rule for distributing computation.
  • D: That describes model partitioning, whereas data parallelism distributes examples across model copies.

9. A streaming assistant emits a first token in 100 ms but completes validation in 5 seconds. Which claim is defensible?

  1. Time to first token is 100 ms; complete validated-response time is 5 seconds
  2. The full validated answer took 100 ms
  3. The answer is correct because the first token was quick
  4. The model trained for 5 seconds on this request

Correct: A.

  • A: These measurements describe different milestones and neither alone certifies answer correctness.
  • B: The first emitted token precedes final output completion and validation.
  • C: Emission speed is not evidence of task correctness or grounding.
  • D: Inference completion time does not establish that weights were updated.

10. A request runs two required independent checks in parallel, taking 300 ms and 500 ms, then performs 200 ms of validation. Ignoring other overhead, what is its latency?

  1. 1,000 ms
  2. 500 ms
  3. 700 ms
  4. 200 ms

Correct: C.

  • A: Adding both independent branches overcounts their overlapping execution.
  • B: The slower parallel branch completes at 500 ms, but subsequent validation still takes 200 ms.
  • C: Both branches must finish, so max(300, 500) + 200 = 700 ms under these assumptions.
  • D: Validation cannot replace the required preceding checks.

11. A controlled test costs 18 units, including failed attempts, and produces 300 confirmed acceptable results in 60 seconds. Which summary is correct?

  1. 300 results/s and 18 units/result
  2. 5 acceptable results/s and 0.06 units/acceptable result
  3. 60 acceptable results/s and 5 units/acceptable result
  4. 0.06 results/s and 5 units/acceptable result

Correct: B.

  • A: The counts must be divided by their respective time and successful-result denominators.
  • B: 300/60 = 5 and 18/300 = 0.06; the quality claim is limited to the stated confirmed results.
  • C: This confuses the test duration and derived throughput with cost per result.
  • D: This reverses the correctly calculated useful rate and cost.

12. A load test waits for each answer before sending the next request, uses only warm-cache short prompts, and reports a good p50. What is missing before a busy launch?

  1. Nothing; the test proves all traffic patterns meet p99 requirements
  2. Only a higher official practice badge score
  3. A rule that all model stages must run on the same GPU
  4. Realistic independent arrivals, bursts, lengths, misses, cold starts, failures, and tail/quality measures

Correct: D.

  • A: One favorable median under serialized warm requests cannot establish production tails.
  • B: Exam classifications do not establish system capacity or benchmark representativeness.
  • C: Hardware co-location is not a universal remedy for an unrepresentative benchmark.
  • D: These conditions reveal queues and resource limits hidden by the favorable serialized test.

13. What does language-model prefix caching most directly reuse?

  1. A guaranteed factually correct final answer
  2. A previous user's approval for a new payment
  3. A training label that automatically updates weights
  4. Compatible calculations for a matching token prefix

Correct: D.

  • A: Computation reuse does not verify facts or return an independently validated answer.
  • B: Approval is bound to its operation and current conditions, not reusable model calculation state.
  • C: Prefix caching concerns inference calculations, not supervised learning updates.
  • D: Reusing earlier computation can save work but requires matching configuration and safe scope.

14. A compatible inference batch of 6 takes 120 ms. A request waits 30 ms for its batch. Ignoring other overhead, which statement is correct?

  1. Every request's latency is 20 ms
  2. Ideal stage throughput is 50 requests/s; this request waits at least 150 ms for its result
  3. System throughput is guaranteed 50 requests/s under all workloads
  4. Batch collection time disappears from end-to-end latency

Correct: B.

  • A: 120/6 is not the elapsed time each request waits for its batched result.
  • B: 6/0.12 = 50, while 30 ms collection plus 120 ms execution gives 150 ms before other stages.
  • C: An ideal continuously occupied stage rate excludes routing, other bottlenecks, and arrival patterns.
  • D: The caller experiences waiting before execution as part of the journey.

15. A cached policy answer has an unexpired TTL, but its source policy was superseded this morning. What should happen?

  1. Return it because expiry is the only validity condition
  2. Keep it if the wording sounds confident
  3. Invalidate or reject affected reuse and check the current authorized source
  4. Treat the source change as proof that every answer needs model retraining

Correct: C.

  • A: Source changes can invalidate an entry before its TTL ends.
  • B: Confidence does not establish current authoritative policy.
  • C: Cache validity depends on current facts and relevant versions, not just age.
  • D: Updating evidence or invalidating reuse can address source freshness without changing weights.

16. A semantic cache treats 'approve 10 units' and 'do not approve 10 units' as similar. What is the most important safeguard?

  1. Require task-appropriate equivalence checks or avoid this reuse for consequential decisions
  2. Raise hit rate by removing the word not from every key
  3. Execute the old approved action whenever similarity is high
  4. Use a longer TTL to ensure similarity becomes correct

Correct: A.

  • A: Similarity can miss a negation that reverses the decision; execution still needs current authorization and approval.
  • B: Discarding the negation deliberately makes opposite requests collide.
  • C: A cached answer does not authorize replaying a consequential operation.
  • D: Entry lifetime cannot repair a semantic mismatch.

17. Which statement distinguishes sharding from replication?

  1. Both guarantee recoverable data before an accidental deletion
  2. Sharding keeps identical copies; replication partitions different records
  3. Sharding partitions data or work; replication maintains copies
  4. Sharding means increasing one processor's clock speed

Correct: C.

  • A: Live copies may replicate deletion, and partitions are not recovery copies.
  • B: This reverses the two concepts.
  • C: Partitions can distribute capacity, while copies can support availability or reads; neither alone proves restore capability.
  • D: Increasing a local resource is vertical scaling, not partitioning the workload.

18. A queue holds 480 jobs. Workers sustainably finish 50 jobs/s while 30 new jobs/s continue to arrive. Under constant rates, how long does it take to drain?

  1. 9.6 seconds
  2. 16 seconds
  3. The queue cannot drain while any arrivals continue
  4. 24 seconds

Correct: D.

  • A: 480/50 ignores ongoing arrivals that consume part of completion capacity.
  • B: 480/30 uses arrival rate rather than the positive net drain rate.
  • C: It can drain when completion capacity exceeds the ongoing arrival rate.
  • D: The net drain rate is 50 − 30 = 20 jobs/s, so 480/20 = 24 seconds.

19. Five ready replicas each sustain 20 requests/s. One fails, and a shared provider permits only 70 requests/s. What is the ideal upper limit before other overhead?

  1. 70 requests/s
  2. 80 requests/s regardless of the provider limit
  3. 100 requests/s
  4. 350 requests/s

Correct: A.

  • A: Remaining replicas total 80 requests/s, but the shared 70 requests/s limit is lower; actual performance still needs verification.
  • B: The four-replica sum does not bypass the shared dependency quota.
  • C: This counts the failed replica and ignores the shared limit.
  • D: A shared quota is not separately available in full to each replica.

20. A known launch burst begins in one minute, but new model replicas need five minutes to load. Which plan most directly protects the launch?

  1. Rely only on scaling after CPU reaches 100%
  2. Pre-scale ready capacity where possible and enforce bounded admission and evaluated degradation
  3. Accept unlimited jobs and label them all completed immediately
  4. Retry every rejection indefinitely at every layer

Correct: B.

  • A: Reactive provisioning starts too late for the stated loading delay and may miss other bottlenecks.
  • B: Startup-aware capacity and overload safeguards address demand while new instances become ready.
  • C: Intake acknowledgment cannot truthfully represent completion and unbounded queues threaten deadlines.
  • D: Uncontrolled retries amplify overload rather than supply missing ready capacity.

21. Which placement concept most directly addresses a validated workload that must continue during internet disconnection near a sensor?

  1. An unapproved remote API with no local path
  2. Edge processing with approved local data, updates, and recovery behavior
  3. A claim that every private cloud is physically on-premises
  4. A larger cross-region transfer for every reading

Correct: B.

  • A: A remote-only dependency cannot meet the stated disconnected requirement.
  • B: Near-source execution can support offline operation, while security and stale-state handling still matter.
  • C: Private cloud describes dedicated use and can be hosted elsewhere.
  • D: Mandatory remote transfers preserve the connectivity dependency rather than remove it.

22. An outage starts at 14:00. Recoverable state is from 13:52 and validated service resumes at 14:35. Objectives are RTO 30 minutes and RPO 10 minutes. What is the result?

  1. Both objectives met because machines restarted
  2. RTO met; RPO missed
  3. Both objectives missed because any data gap is forbidden
  4. RTO missed by 5 minutes; RPO met with an 8-minute data gap

Correct: D.

  • A: The required service was interrupted for 35 minutes, exceeding the 30-minute recovery target.
  • B: This reverses the result: interruption is too long, but the eight-minute data gap is within target.
  • C: The stated RPO permits up to ten minutes; the observed eight-minute gap is within it.
  • D: 14:00 to 14:35 is 35 minutes, while 13:52 to 14:00 is eight minutes under the stated recovery evidence.

23. Two regions have healthy inference replicas but both depend on one unavailable identity service. What does this show?

  1. Different regions guarantee every dependency is independent
  2. Identity checks should be silently disabled during failover
  3. A shared dependency can defeat otherwise redundant serving capacity
  4. The system has proven its backup restore meets RPO

Correct: C.

  • A: Geographic separation does not remove a shared required service.
  • B: An outage cannot justify bypassing required authentication or authorization.
  • C: Useful recovery must include identity and other required dependencies, not just model hosts.
  • D: Replica health and identity failure provide no recovered-data-gap evidence.

24. A hosting option has the lowest hourly compute price but needs more staff, idle recovery capacity, and costly data transfers. How should it be compared?

  1. Compare total cost of meeting quality, permissions, service, and tested recovery requirements
  2. Select it solely from the lowest processor price
  3. Ignore recovery because an SLA guarantees no outages
  4. Declare compliance from its cloud or on-premises label

Correct: A.

  • A: Useful service cost includes operational labor, transfers, headroom, evaluation, and recovery, not only a processor rate.
  • B: A component price can conceal larger operating and dependency costs.
  • C: Agreements can have consequences for failure but do not eliminate outages or the need for recovery.
  • D: Placement labels do not establish current legal obligations or actual controls.
