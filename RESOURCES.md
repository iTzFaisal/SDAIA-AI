# AI Engineer Expert Exam Resources

## Knowledge

- [AI Engineer Expert badge blueprint](./AI-Badge.png)
  The authoritative source for this workspace's seven domains, weights, and claimed exam format. Use it when deciding coverage and practice allocation.
- [SDAIA AthkaX](https://sdaia.gov.sa/en/Sectors/BuildingCapacity/Pages/athkax.aspx)
  First-party overview of the badge platform and its capability-oriented assessment context. Use for high-level framing, not for unlisted exam item details.
- [AthkaX AI Engineer badge record](https://athkax.sdaia.gov.sa/badges/61af22d9-2e3e-4412-9675-e8b4504a7d20)
  First-party badge description covering design, build, deployment, operation, evaluation, integration, reliability, security, governance, and collaboration.
- [Google Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course)
  Structured foundation for supervised learning, data preparation, generalization, embeddings, and fairness. Use for prerequisite repair and early domain labs.
- [scikit-learn model evaluation](https://scikit-learn.org/stable/modules/model_evaluation.html)
  Reference for classification, regression, clustering, and metric-selection trade-offs. Use when reviewing evaluation choices.
- [PyTorch tutorials](https://pytorch.org/tutorials/)
  First-party practical material for tensors, autograd, training loops, and production-adjacent model work. Use for deep-learning labs.
- [Deep Learning](https://www.deeplearningbook.org/)
  Open textbook by Goodfellow, Bengio, and Courville. Use for deeper explanations of optimization, regularization, and representation learning.
- [Attention Is All You Need](https://arxiv.org/abs/1706.03762)
  Primary paper introducing the Transformer architecture. Use when the GenAI path needs an architectural explanation rather than API-level familiarity.
- [Hugging Face course](https://huggingface.co/learn/nlp-course/chapter1/1)
  First-party course for Transformers, tokenizers, datasets, fine-tuning, and inference. Use for applied GenAI practice.
- [MLflow documentation](https://mlflow.org/docs/latest/ml/tracking/)
  Reference for experiment tracking and model lifecycle practices. Use in the MLOps route.
- [Google SRE book](https://sre.google/sre-book/table-of-contents/)
  High-trust reference for service-level objectives, monitoring, incident response, and reliability trade-offs. Use for deployment and operations scenarios.
- [Kubernetes concepts](https://kubernetes.io/docs/concepts/)
  First-party reference for workloads, services, scheduling, scaling, and configuration. Use for infrastructure and scalability mapping, not as a prerequisite for every learner.
- [Docker Get Started](https://docs.docker.com/get-started/)
  First-party introduction to packaging and running reproducible services. Use for the local capstone deployment boundary.
- [FastAPI documentation](https://fastapi.tiangolo.com/)
  First-party reference for typed API boundaries, validation, and service integration. Use when the software-engineering lab exposes a model safely.
- [NIST AI Risk Management Framework](https://www.nist.gov/itl/ai-risk-management-framework)
  Primary public framework for identifying, measuring, managing, and governing AI risks. Use across responsible AI and governance scenarios.
- [NIST Generative AI Profile](https://www.nist.gov/itl/ai-risk-management-framework/ai-rmf-generative-ai-profile)
  Companion guidance for risks specific to generative systems. Use for the RAG and LLMOps safety review.
- [OWASP Top 10 for Large Language Model Applications](https://owasp.org/www-project-top-10-for-large-language-model-applications/)
  Security threat reference for prompt injection, insecure output handling, data leakage, and related LLM application risks.
- [MITRE ATLAS](https://atlas.mitre.org/)
  Knowledge base for adversarial tactics and techniques against machine-learning systems. Use to build threat models and security scenarios.
- [ACM Code of Ethics](https://www.acm.org/code-of-ethics)
  Professional reference for public good, harm avoidance, privacy, fairness, and professional responsibility.
- [SDAIA National Occupational Standard Framework](https://sdaia.gov.sa/en/Research/Pages/NOSF.aspx)
  First-party occupational reference for AI tasks, knowledge, skills, and abilities. Use to connect technical decisions to professional practice.

## Wisdom (Communities)

- [MLOps Community](https://home.mlops.community/)
  Practitioner community for operating machine-learning systems. Use for real-world operational patterns and postmortem perspectives, not exam facts.
- [Hugging Face forums](https://discuss.huggingface.co/)
  Practitioner discussions around Transformers, datasets, evaluation, and inference. Use to compare implementation experiences.
- [PyTorch forums](https://discuss.pytorch.org/)
  Technical community for debugging and understanding deep-learning behavior. Use after attempting a problem independently.
- [OWASP community](https://owasp.org/)
  Security community and project ecosystem. Use to pressure-test threat models and controls.

## Gaps

- No public item-level blueprint, official pass mark, sample exam, or per-domain question allocation is included in the supplied material. The course uses the image for its working blueprint and labels preparation thresholds as internal targets.
- The exact runtime stack for the exam is unspecified. Labs therefore stay cloud-neutral and teach transferable decisions rather than vendor memorization.
