Practice reference

Route selection

Diagnose before you schedule

Answer each prompt from memory, reveal the reference answer, then rate your current confidence. This tool chooses a study pace; it does not estimate the official exam result.

1. Data, ML foundations, and evaluation

Why should the test set remain untouched until model choices are finished?

Reveal a reference answer

It should estimate performance on relevant unseen data. Tuning against it makes the estimate optimistic because the test set has influenced decisions.

2. Core AI, deep learning, and generative AI

When would retrieval-augmented generation be preferable to fine-tuning?

Reveal a reference answer

Prefer retrieval when knowledge changes, is private, needs source grounding, or should be updated without changing model weights. Fine-tuning solves a different class of adaptation problem.

3. AI software engineering and integration

What boundary keeps model behavior from leaking unpredictably into product code?

Reveal a reference answer

Use an explicit, versioned interface with input validation, output schemas, timeouts, and defined failure behavior. The boundary makes the AI component replaceable and testable.

4. MLOps, LLMOps, deployment, and reliability

What should be monitored after deployment beyond uptime?

Reveal a reference answer

Monitor quality, drift, latency, cost, safety signals, and meaningful user outcomes. An available service can still be producing harmful or useless answers.

5. Architecture, infrastructure, performance, and scalability

What information do you need before deciding whether to batch, cache, or scale a model service?

Reveal a reference answer

Start with workload shape, latency and throughput targets, request sizes, cost limits, dependency behavior, and quality constraints. The bottleneck and SLO determine the right lever.

6. Responsible AI, security, and governance

A model is accurate overall but poor for a protected subgroup. Is it ready?

Reveal a reference answer

Not automatically. Investigate subgroup performance, context, possible harm, data limitations, mitigation options, and the accountable approval process before release.

7. Business, professional practice, and collaboration

What makes an AI recommendation useful to a decision-maker who is not an ML specialist?

Reveal a reference answer

Connect the recommendation to an outcome, constraints, uncertainty, alternatives, risks, and an explicit decision request. Technical accuracy alone does not create organizational value.
